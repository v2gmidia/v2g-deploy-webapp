## Proposta visual exata para produção

Peça estática quadrada, composição de **1080 × 1080**, sem foto inventada ou gráficos de desempenho. Este é o desenho editorial, não um arquivo de anúncio pronto:

```text
┌─────────────────────────────────────────────┐
│                                             │
│  [Marca própria V2G]                         │
│                                             │
│  Você cuida                                 │
│  do negócio.                                │
│                                             │
│  A V2G cuida                                │
│  dos anúncios.                              │
│                                             │
│  Gestão de anúncios com                     │
│  acompanhamento humano.                     │
│                                             │
│  Converse com a V2G                         │
│                                             │
└─────────────────────────────────────────────┘
```

- **Marca:** usar a marca própria vigente, sem redesenhar símbolo/logotipo. Há símbolo vetorial no repositório (`public/marca-editorial.svg`); o PNG v1 é referência do conjunto visual, não fonte para copiar texto antigo. Fonte editável completa do anúncio ainda não localizada.
- **Fundo:** azul-marinho sólido da marca (`#051225`), sem gradiente, textura tecnológica ou circuito decorativo.
- **Tipografia:** Archivo. Margens mínimas propostas de 80 px; a composição inteira deve respirar e permanecer legível na prévia móvel.
- **Frase principal:** em quatro linhas, como no desenho; peso forte, cerca de 88–96 px no arquivo de 1080, ajustado pelo produtor para não cortar palavras. Primeiro par branco; segundo par azul-claro `#B0E9FD`, com contraste sobre o fundo marinho.
- **Apoio:** branco, 32–36 px, separado da frase principal. A presença humana precisa continuar legível; não virar rodapé minúsculo.
- **Chamada:** “Converse com a V2G”, branca, sem simular painel, dado ou botão funcional do aplicativo. O botão real de mensagem é configurado na Meta.
- **Evitar:** preço de serviço ou promessa de venda sem decisão específica; “IA”, robôs, telas fictícias, gráficos, resultados inventados, foto de gestor/cliente sem material próprio autorizado e mídia de concorrente.
- **Entrega de produção:** PNG/JPG exportado, dimensões verificadas, conferência em celular e novo hash. Para outro posicionamento, preparar versão própria; não esticar o quadrado.
